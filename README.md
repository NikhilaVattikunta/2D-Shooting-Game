# 🎮 2D Shooting Game (Java)

## 🚀 Features
- Multi-directional shooting
- Enemy AI movement (zig-zag, random)
- Power-ups (health & rapid fire)
- Collision detection
- Game over & restart system
- Persistent high score (file storage)

## 🛠️ Tech Stack
- Java (Swing)
- Object-Oriented Programming
- File Handling (for high score)

## 🎮 Controls
- W A S D → Move
- Arrow Keys → Shoot
- Space → Shoot forward
- R → Restart

## ▶️ How to Run
1. Open in IntelliJ
2. Run Game.java
